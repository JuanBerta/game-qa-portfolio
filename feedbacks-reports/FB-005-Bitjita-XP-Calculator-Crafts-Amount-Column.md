# FB-005: Add Total Crafts / Items Output Column to XP Calculator

## Problem Description
Currently, Bitjita's **XP Calculator** table displays metrics for `XP/action`, total `Actions`, and estimated `Time` required to reach a target skill level. However, it does not explicitly state the total number of **Crafts** or **Finished Items** generated by completing those actions.

For multi-tick or multi-effort crafting recipes where `Actions` corresponds to individual effort ticks rather than completed recipes, users are forced to manually divide the total actions by ticks-per-craft to figure out how many actual items/recipes they need to prepare resources for.

---

## Proposed Solution
Add a **"Crafts" / "Total Output"** column to the XP Calculator results table alongside the existing `Actions` column:

1. **Crafts / Batches Column:** Display the exact number of completed craft cycles needed to reach the target XP goal (e.g., *Total Items Produced*).
2. **Clear Metric Distinction:** Keep `Actions` (individual work/effort ticks) separated from `Crafts` (completed recipe outputs) so players know both the time/effort cost and the exact material batch quantity required.

---

## User Experience & Value
* **Easier Resource Planning:** Players can immediately see how many items they need to craft to hit a target level without doing manual math on tick ratios.
* **Streamlined Crafting Prep:** Makes it easy to match resource acquisition directly with the required number of completed crafts in a single view.
