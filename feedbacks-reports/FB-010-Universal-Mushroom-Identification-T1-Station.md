# FB-010: Allow All Mushroom Tiers to Be Identified at T1 Foraging Stations

## Problem Description
Currently, identifying harvested mushrooms requires using a Foraging Station of an equivalent or higher tier to the mushroom being identified (e.g., a T4 mushroom requires a T4+ Foraging Station). 

This requirement imposes an unnecessary logistical burden when exploring or gathering in higher-tier regions. Players who gather high-tier mushrooms far from major hubs must haul unidentified resources back to high-tier stations or build high-tier stations locally just to process their gather, creating excessive friction for basic identification.

---

## Proposed Solution
Standardize the mushroom identification process so that **any Mushroom tier can be identified using a Tier 1 (or any) Foraging Station**:

1. **Universal Identification Requirement:** Set the workstation requirement for mushroom identification across all tiers to T1 Foraging Stations.
2. **Preserve Skill/Tier Gates:** Keep skill level requirements or recipe costs tied to the mushroom tier itself, while removing the strict station-tier placement barrier for the identification step.

---

## User Experience & Value
* **Streamlined Field Logistics:** Players can process and identify their gathered mushrooms at basic outposts without needing to transport raw unidentified yields across long distances to high-tier crafting hubs.
* **Consistent Foraging Workflow:** Aligns mushroom identification with a smoother gameplay loop, reducing inventory clutter during long exploration trips.
